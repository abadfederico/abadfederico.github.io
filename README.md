# Personal Webpage Source

This repository contains the source code for a simple personal webpage.

## Folder structure

- `css/` – Stylesheets used by the site
- `img/` – Images and other media assets
- `js/`  – JavaScript files

The main entry point is `index.html` which references the content inside these folders.

## Serving the site

Any static file server can be used to preview or deploy the page. For example, run `python -m http.server` in the repository root and open the displayed URL in a browser.
